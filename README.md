# CRM Dashboard

A modern CRM (Customer Relationship Management) Dashboard built using HTML, CSS, and Bootstrap 5.


## live link
https://ismailhussainx0.github.io/CRM/



## Features

- Dashboard Overview
- Customers Management
- Leads Management
- Employees Page
- Tasks Management
- Meetings Schedule
- Calendar Page
- Reports Dashboard
- Notifications
- Settings Page
- User Profile

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
